Where to Find Your TxID / Hash

A TxID (Transaction Hash) is a unique code generated by your crypto wallet after you send funds. Here is how to find it in your wallet:

Coinbase & Coinbase Wallet

Go to Assets -> Tap the Crypto Sent (BTC/SOL/LTC) -> Select transaction -> Tap View on Block Explorer or copy Hash.

Phantom & Solflare (Solana)

Open Activity (⚡) -> Tap the recent sent transaction -> Tap Signature / TxID to copy.

Trust Wallet & MetaMask

Tap Sent Transaction -> Select More Details -> Copy Transaction Hash / TxHash.

Binance / CashApp / Exodus / Kraken

Go to Wallet History / Transactions -> Tap Withdrawal Details -> Copy the TxID code.
